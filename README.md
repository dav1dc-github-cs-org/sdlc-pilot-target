# sdlc-pilot-target

Sandbox target repository for the cross-repository SDLC pilot
([agentic-sdlc-prototype#35](https://github.com/dav1dc-github-cs-org/agentic-sdlc-prototype/issues/35)).
Its control plane is
[sdlc-pilot-control](https://github.com/dav1dc-github-cs-org/sdlc-pilot-control).

Small TypeScript text utilities under `src/`, tested with Node's test runner.

```sh
npm ci --ignore-scripts
npm run verify
```
